# Note

텍스트 메모와 손필기 메모를 작성일자별로 관리하는 정적 웹 앱입니다.

## 실행

```sh
python3 -m http.server 8000
```

브라우저에서 실행한 서버에 접속하세요. 별도의 빌드나 패키지 설치는 필요하지 않습니다. 화면 스타일은 Tailwind CDN을 사용합니다.

## 메모 작성

- 첫 화면 오른쪽 아래의 **＋ 원형 버튼**을 누르고 **텍스트 메모 / 필기 메모**를 선택합니다. 선택한 메모 전용 편집기가 열립니다.
- 각 메모의 작성일자와 한 줄 요약을 입력하고 해당 저장 버튼을 누릅니다. 텍스트 요약을 비우면 본문 일부가 목차에 표시됩니다.
- 목차는 작성일자 최신순입니다. 메모를 선택하면 다시 편집할 수 있습니다.

## 필기 도구

- 펜, 만년필, 연필, 형광펜, 지우개와 직선·사각형·원 도구를 제공합니다. 도형은 끌어서 그립니다.
- 도구마다 굵기를 기억하며 기본 색상 6가지와 사용자 색상을 선택할 수 있습니다. 스타일러스의 필압은 펜·만년필·연필 굵기에 반영됩니다. 만년필은 45도 방향의 얇고 넓은 납작촉으로, 획 방향에 따라 가는 선과 굵은 선이 달라집니다.
- 실행 취소와 다시 실행은 현재 편집 중인 최근 24단계까지 지원합니다. 전체 지우기도 취소할 수 있습니다. 메모를 다시 열거나 페이지를 이동하면 실행 취소 내역은 초기화됩니다.
- 편집창에서 Ctrl/Cmd+Z로 실행 취소, Shift+Ctrl/Cmd+Z로 다시 실행합니다. 텍스트 입력 중에는 브라우저의 텍스트 편집 단축키가 유지됩니다.
- 모눈·줄노트·무지 용지를 선택할 수 있으며 용지 종류도 메모에 저장됩니다.
- **넓게 쓰기**로 필기 영역을 확장하고 Escape 또는 **원래 크기**로 돌아옵니다.
- **펜으로만 쓰기**는 스타일러스 입력만 받습니다. 이 모드에서 필기 패널은 두 손가락으로만 위아래 스크롤되며, 한 손가락은 무시됩니다. 펜은 화면을 스크롤하지 않고 필기만 합니다. 아이폰에서 손가락으로 쓰려면 이 옵션을 끄세요. 필압 감지와 스타일러스 지원은 기기·브라우저에 따라 다릅니다.
- **이미지 저장**은 현재 페이지의 필기와 용지 배경을 PNG로 내려받습니다. 화면 회전이나 창 크기 변경은 원본 필기에 영향을 주지 않습니다.

## 저장 및 선택 기능

메모는 현재 사이트의 브라우저 저장소(localStorage)에 저장됩니다. 다른 기기로 자동 동기화되지 않으며 브라우저 데이터를 삭제하면 사라집니다. 중요한 필기는 PNG로도 보관하세요. 저장 공간이 부족하면 오류 안내가 표시되고 편집 중인 내용은 유지됩니다.

AI 요약은 화면에 Gemini API 키를 입력해야 합니다. 키는 메모와 함께 저장하지 않습니다. 받아쓰기는 음성 인식을 지원하는 브라우저와 마이크 권한이 필요합니다.

## 필기 입력 회귀 검증

Playwright와 Chromium이 설치된 환경에서 `node tests/handwriting.cjs`를 실행합니다. Chromium 경로는 `CHROMIUM_PATH`로 지정할 수 있습니다. 검증은 임시 로컬 서버를 띄워 실제 브라우저 입력으로 필압, 납작촉의 획 방향, 한 손가락 무시·두 손가락 스크롤, 펜 필기, 실행 취소와 화면 크기 변경을 확인합니다. 실제 기기의 필압 지원 여부와 Safari 터치 동작은 기기에서도 확인해주세요.

## A4 페이지와 작은 도구 모음

필기 영역은 세로 A4 비율(210:297)입니다. 아래 **＋ 페이지 추가**를 누르면 빈 다음 페이지가 열리고, **이전 / 다음**으로 페이지를 이동할 수 있습니다. **저장**은 모든 페이지를 함께 저장합니다. 기존 가로형 필기는 비율을 유지해 첫 페이지 위쪽에 불러옵니다.

도구·실행 취소·다시 실행은 아이콘으로 표시합니다. 필기 날짜·요약 및 용지·펜 전용 모드 등의 설정은 접힌 메뉴에서 펼칠 수 있습니다.

## 녹음

상단의 **🎙️ 녹음**을 누르고 마이크를 허용하면 필기나 페이지 이동 중에도 녹음됩니다. **⏹ 녹음 중지**를 누르면 녹음 내역에 보관되며 재생·다운로드할 수 있습니다. 녹음 중에는 중지 버튼이 화면 위에 유지됩니다.

녹음은 메모와 별도의 녹음 내역으로 현재 브라우저의 IndexedDB에 저장됩니다. 클라우드 업로드나 기기 간 동기화는 하지 않습니다. 저장 실패 시 페이지를 닫기 전에 다운로드해주세요. 브라우저 데이터 삭제 시 녹음도 삭제됩니다.

새 녹음은 오디오 MP4(M4A)로 저장하며 AAC를 지원하면 우선 사용합니다. 실제 오디오 코덱은 브라우저에서 지원하는 인코더를 따릅니다. M4A를 지원하지 않는 브라우저에서는 다른 형식으로 녹음하지 않고 안내합니다. 이전 WebM 녹음은 원래 형식으로 재생·다운로드할 수 있으며 자동 변환하지 않습니다.

HTTPS 또는 localhost와 M4A MediaRecorder 지원 브라우저가 필요합니다. 앱을 열어둔 채 필기하는 동안 녹음할 수 있지만, iOS 화면 잠금·다른 앱 전환 중 녹음 지속은 보장되지 않습니다. 권한 거부나 마이크 오류는 화면에 안내합니다.

`node tests/notebook.cjs`로 목차 종류 선택, 모바일 도구 모음, A4 여러 페이지 저장·복원, 이전 메모 호환, 녹음·재생·다운로드·권한 오류를 확인할 수 있습니다. 테스트 녹음은 Chromium 가상 마이크를 사용하며 실제 기기·마이크 검증은 별도로 필요합니다.
